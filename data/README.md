# Data

The challenge's primary dataset is the Kaggle **Customer Support on Twitter** dataset by Thought Vector.

Do not commit the full dataset to this repository unless your use/licensing situation permits it. The project is designed to run with a small sample and to reproduce the full pipeline locally after the evaluator downloads the dataset.

Expected file:

`data/customer_support_on_twitter.csv`

Required columns:

- `tweet_id`
- `author_id`
- `inbound`
- `created_at`
- `text`
- `response_tweet_id`
- `in_response_to_tweet_id`

The shipped demo sample contains Apple Support examples extracted from a public Kaggle slice for reproducibility of the UI/demo path.

| File | Purpose |
|---|---|
| `apple_support_sample.csv` | Raw Kaggle slice (11 inbound tweets) |
| `examples.json` | Retrieval corpus (generated by `scripts/prepare_demo_data.py`) |
| `golden_eval.csv` | 180 hand-labelled evaluation examples |
| `eval_results.json` | Latest metrics from `scripts/evaluate.py` |
| `GOLDEN_SET_NOTES.md` | Sampling and labelling protocol |
